Helios

Guia da equipe. Cada peça do projeto funciona sozinha. O difícil, e o que vai decidir tudo, é a costura entre elas.

Regras da costura

  • Teste cada peça sozinha antes de ligar na outra.
  • Teste cada conexão com um valor falso antes de usar o real.
  • Nenhum nome de campo muda sem avisar o grupo e a Tamiris.
  • Chaves e senhas não vão para o GitHub nem para o grupo aberto.

Quem faz o quê

No fim de cada ficha há um prompt pronto para pedir ajuda à IA. Preencha os colchetes e cole junto o seu código e as mensagens de erro. Se não entender um termo, peça para a IA explicar do zero. Ela também erra: teste tudo e só use o que você entendeu.

Marcos

Na ordem. Só passe ao próximo quando o anterior funcionar de verdade. Os testes de integração são feitos em dupla rotativa, e a Tamiris registra cada resultado.
